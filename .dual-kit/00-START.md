# Premier démarrage

Lire les règles EXISTANTES du projet et le profil accepté, puis le protocole.
Détecter NOUVEAU/EXISTANT, stack, outils, branche, HEAD, changements locaux,
source des tâches et accès réels de A/B. Noter vérifié/absent/inconnu.
Ne jamais écraser AGENTS, README, CI, NOW, backlog ou ADR.

Nouveau : PRD minimal, acceptation, comparaison de deux architectures compatibles
avec les capacités vérifiées, décision ADR. Existant : lire le code concerné,
préserver stack et décisions, corriger dans le mandat seulement.

Sélectionner une tâche autorisée, réserver et recontrôler avant écriture ; exécuter
les tests applicables, publier les preuves sur la source commune, demander revue B.
Sans B active : WAITING_AGENT, jamais APPROVED. Un prompt ne crée pas de scheduler.
Ne demander au propriétaire que les décisions ou autorisations indispensables.
Rendre faits, hypothèses, tests et prochaine action séparément et brièvement.
